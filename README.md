# Smart Event Dashboard 

A smart event dashboard web application built using HTML, CSS, and JavaScript to manage and display event data dynamically with an interactive user interface.

## Features

* Display and manage event details dynamically
* Interactive UI with real-time updates
* Responsive design for multiple screen sizes
* User-friendly layout for better experience

## Tech Stack

* HTML
* CSS
* JavaScript

## Live Demo

https://quiet-douhua-93a4f8.netlify.app/

## Project Structure

* `index.html` – Structure of the dashboard
* `style.css` – Styling and layout
* `script.js` – Logic and dynamic functionality

## How to Run Locally

1. Download or clone the repository
2. Open project folder
3. Run `index.html` in browser
